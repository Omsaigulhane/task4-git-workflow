\# Task 4: Version-Controlled DevOps Project



\## Objective

Demonstrate Git and GitHub best practices using commits, branches, pull requests, tags, and documentation.



\## Tools

\- Git

\- GitHub

\- PowerShell



\## Workflow

1\. Initialize a Git repository.

2\. Create and push the main branch.

3\. Create development and feature branches.

4\. Make changes and commit them.

5\. Merge changes using GitHub pull requests.

6\. Use `.gitignore` and Git tags.



\## Learning Outcomes

\- Understand Git version control.

\- Practice branching and merging.

\- Review changes using pull requests.

\- Maintain a documented project history.
